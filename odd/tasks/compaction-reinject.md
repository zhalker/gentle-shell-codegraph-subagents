# Reinject the CodeGraph notice after compaction, and a short on-screen line
After a compaction the model no longer sees the index notice and the skill reminder; they come back once on the next user prompt. On screen the first one shows as a short expandable line and the reinjected ones stay hidden.
Branch: `feat/compaction-reinject` from `main` (c234f5e, includes PR #6). Release target: 0.4.0 (version bump, tag and GitHub release; `npm publish` stays with the user).

## Specs

- S1. "pensaba que despues de cada compactacion inyectar otra vez lo mismo que se hace al inicio de una sesion en el primer prompt". After each compaction, the next user prompt carries again the index notice and the codegraph-workflow skill reminder, under the same conditions as at session start (index present, CodeGraph tool held, packaged skill selected, worker marker for children), once per compaction. A notice or reminder that is still in the model's context (after the last compaction's kept boundary) is not sent again. The explorer pre-fetch is not reinjected (L2).
- S2. "Sobre la linea corta expandible me parece bien solo para el de al iniciar la sesion, el primero." The first-prompt message is shown in the transcript as one short line that expands to the full text. The text the model receives is unchanged.
- S3. "Para los que van despues de compactar se ocultan siempre." A message reinjected after compaction is never displayed in the transcript.
- S4. "quiero llegar a la 0.4.0 con nuevas funcionalidades justificadas". Version 0.4.0 with PR #6 and S1-S3; README and docs describe the new behavior; tag v0.3.0-style annotated tag `v0.4.0` and a GitHub release.
