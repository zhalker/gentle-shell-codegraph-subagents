# agent-file-freeze
Stop this extension from freezing gentle-pi agent files: any edit to `~/.pi/agent/agents/*.md` makes gentle-pi stop refreshing them on upgrades.
Evidence: `docs/findings.md`, section "Upstream state on 2026-11-08". Engram mirror: `odd/agent-file-freeze/tasks`.

T5 design (approved rule + S11): at extension load, outside subagent children, with gentle-pi found at `<agentDir>/npm/node_modules/gentle-pi` (package.json name `gentle-pi`, readable `assets/migrations/agent-body-history.json`), an agent file in `<agentDir>/agents` is repaired only when (1) its single `.pre-codegraph-subagents.bak` exists and that backup's body without gentle-ai blocks is a shipped body, (2) the file without `model:`/`thinking:` lines equals a published normalizer's output (0.1.0 or 0.2.0-0.6.0) of the backup without those lines, or its body (without the worker marker) is shipped, and (3) its `model:`/`thinking:` lines are absent or equal its `~/.pi/gentle-ai/models.json` entry. Swap, not delete: the file is renamed atomically to a temporary pending name; after the startup (first prompt) and again at the next load, the swap is settled: if gentle-pi recreated the file, the pending copy is removed; if not, the pending copy is renamed back (rollback) and that file is not retried while unchanged. No new `.bak`; the existing backup is never modified. Every repaired, rolled-back and skipped file is reported with its reason.
