# codegraph-subagents
Pi package (npm) that guarantees CodeGraph reaches gentle-shell subagents. Upstream issue: Gentleman-Programming/gentle-shell#2804.
Context and verified evidence: `docs/findings.md`. Engram mirror: `odd/codegraph-subagents/tasks` (project `zh_lia`, topic `gentle-shell/codegraph-subagents-extension-plan`).
